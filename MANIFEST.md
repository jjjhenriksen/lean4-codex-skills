# Skill Manifest

## `lean4-mentor`

Use for Lean 4 orientation, especially when the user wants to understand Lean as
an interactive semantic environment rather than only as a proof assistant.

Includes:

- `references/mentor-orientation.md`

## `lean4-learn`

Use for concept explanation, guided exploration, small examples, repository
tours, and mathlib navigation.

## `lean4-formalize`

Use for drafting Lean statements from informal prose, creating theorem
skeletons, and beginning formalization workflows.

## `lean4-prove`

Use for filling sorries, proving existing declarations, repairing tactics, and
working through proof goals.

## `lean4-review`

Use for read-only proof review, proof refactoring, Mathlib leverage suggestions,
and proof golfing.

## `lean4-checkpoint`

Use for build-checked save points: file checks, project build, sorry audit,
axiom audit, and careful staging/commit workflows.

## `lean4-doctor`

Use for Lean, Lake, Mathlib, elan, imports, and project-configuration diagnosis.
